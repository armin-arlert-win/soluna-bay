SOLUNA BAY is a 3D third-person open-world crime game built for [make.fun's Make GTA 6 bounty](https://make.fun/bounty/gta6-01): a sunny coastal city to explore on foot and by car, with traffic and pedestrians, carjacking, a 1-5 star wanted level with police chases, roadblocks and a helicopter, story missions, combat, a HUD with minimap, and saves. Vanilla JavaScript + raw WebGL, no build step, playable offline in desktop Chrome.

Run it: open `game/index.html` in Chrome, or serve the folder with any static server and open the page.
